NAINA RATHI — BIRTHDAY WEBSITE
================================
Open index.html in any modern browser.

Pages:
1. Home — live countdown to 25 October 2026
2. Memories — photo gallery using the supplied photos
3. Tareef — compliments/love page
4. A Little Note — personal birthday message
5. Surprise — clickable hidden birthday reveal

All pages work without a server. Internet is only used for the optional Google Fonts;
the site otherwise uses local HTML/CSS/JS and local photos.

Music: The app now uses the user-provided audio for "Jeene Laga Hoon" as looping background music. Browsers may require the first tap/click before audio can start.
